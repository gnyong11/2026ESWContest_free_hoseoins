# SafeNest 센서 안전 대시보드

ESP32 센서와 Raspberry Pi를 연결해 독거인의 현재 생활 상태를 확인하고, 설명 가능한 고정 기준으로 `정상`, `주의`, `위험`을 표시하는 실시간 대시보드입니다. 개인의 과거 생활 패턴을 비교하거나 의료 진단을 수행하지 않습니다.

## 구성

- `/`, `/live`: Raspberry Pi Python API와 결합한 실시간 대시보드
- `raspberry_pi/`: MQTT 수신, 센서 전처리, FSM, SQLite, 위험 판정, 카메라 제어, 대시보드 API

## 현재 안전 규칙

- 침대 장시간 사용: 12시간 이상 주의, 14시간 이상 위험
- 거실 쓰러짐 감지: 서 있음에서 누운 형태로 1.5초 미만에 전환되면 위험
- 야간 외출: 위험도와 분리된 `야간 외출` 상태와 외출 경과시간으로 표시

## 카메라 프라이버시

거실 카메라는 현관 출입 방향을 확인 중이거나, 침실·화장실·침대 센서가 모두 비어 거실 재실 가능성이 있을 때만 작동합니다. 외출 또는 침실·화장실 재실이 확인되면 카메라를 끄고 프라이버시 대기 상태로 전환합니다. 영상은 파일로 저장하지 않으며 메모리의 최신 프레임만 실시간 분석과 화면 전송에 사용합니다.

## 실행

Node.js 22 이상이 필요합니다.

```bash
pnpm install
pnpm dev
```

라즈베리파이 실행 방법은 `raspberry_pi/README.md`를 확인합니다.

```bash
pnpm build
cd raspberry_pi
python -m unittest -v test_safenest.py
```

Wi-Fi 비밀번호, MQTT 비밀번호와 API 키는 저장소에 추가하지 마세요.
